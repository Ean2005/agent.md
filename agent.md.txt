# 專案開發規範 (AGENTS.md)

## 1. 這個專案的目的
本專案為「個人學習筆記與知識庫網站 (Personal Learning Wiki)」，旨在系統化整理各科課程筆記、重點摘要與實作紀錄，並透過 GitHub Pages 提供清晰、好讀的線上瀏覽介面。未來將由 AI 協助持續擴充新的筆記篇章。

## 2. 網頁的整體風格
- **視覺色調**：採用極簡現代風格（Minimalist & Clean），背景為淺灰白色（`#F8FAFC`），卡片底色為純白（`#FFFFFF`），主色調為深藍灰（`#1E293B`），強調色為靛藍色（`#4F46E5`）。
- **排版設計**：使用無襯線字體（`system-ui, -apple-system, "Noto Sans TC", sans-serif`），行距設定為 `1.6`，確保長文閱讀舒適度。
- **響應式設計 (RWD)**：支援電腦與手機瀏覽，左側為固定導覽列（手機版收合於頂部），右側為主要內容區。

## 3. 頁面結構
每個頁面皆必須包含以下三個核心區塊：
1. **側邊導覽列 (Sidebar)**：顯示網站標題、搜尋框（選配）以及所有筆記分類與文章連結清單。
2. **主內容區 (Main Content)**：
   - **文章標頭 (Header)**：包含文章標題、分類標籤 (Badge) 與最後更新日期。
   - **重點摘要框 (Summary Callout)**：以淺色背景區塊列出該篇筆記的 3 個核心重點。
   - **正文區塊 (Body)**：使用清晰的 H2、H3 標題、條列式清單與表格呈現內容。
3. **頁尾區 (Footer)**：標註作者資訊、GitHub 專案連結與「由 AGENTS.md 規範生成」字樣。

## 4. 新增內容時要遵守的格式
當新增一篇筆記或區塊時，必須嚴格遵守以下 HTML 結構規範：
- 每篇筆記必須包裹在 `<article class="note-card">` 標籤內。
- 標題下方必須加上 메타資訊列：`<div class="meta"><span class="tag">分類名稱</span><span class="date">YYYY-MM-DD</span></div>`。
- 開頭必須包含一個 `<div class="summary-box">` 放本篇核心摘要。
- 程式碼或公式區塊必須使用 `<pre><code>` 標籤並套用深色背景樣式。

## 5. 檔案應該如何命名與放置
- **根目錄 (`/`)**：
  - `AGENTS.md`：本專案的 AI 開發規範文件。
  - `index.html`：網站首頁與主要筆記總覽頁面。
- **筆記頁面目錄 (`/notes/`)**（未來擴充時使用）：
  - 檔名一律使用「小寫英文 + 連字號 (kebab-case)」，例如：`notes/week09-ai-agents.html`、`notes/accounting-basics.html`。
- **靜態資源目錄 (`/assets/`)**：
  - 圖片統一放置於 `assets/images/`，命名格式為 `主題-序號.png`。

## 6. AI 修改或新增內容時需要遵守的規則
1. **禁止破壞既有結構**：AI 在新增筆記連結或文章卡片時，絕對不可刪除或覆蓋既有的導覽列連結與舊文章內容。
2. **自動同步導覽列**：每當在主內容區或 `/notes/` 新增一篇文章時，必須同步在左側 `<nav class="sidebar">` 的對應分類下新增一筆 `<li><a href="...">` 連結。
3. **單一檔案獨立性**：為確保 GitHub Pages 可直接靜態預覽，請使用原生 HTML5 與內嵌 CSS（或單一共用 CSS），不引入需要額外編譯打包的複雜框架。
4. **語氣與語言**：所有生成之網頁內容請使用**繁體中文（台灣習慣用語）**，排版需條理分明、重點加粗。
